# Design patterns

## Creational patterns
The Abstract **Factory Design Pattern** is a creational design pattern that provides an interface for creating families of related objects without specifying their concrete classes. Instead of creating objects directly using constructors, the client uses an abstract factory that defines methods for producing different types of related objects, while concrete factories implement these methods to create specific product families. For example, a GUI application could use a Windows factory to create Windows-style buttons and checkboxes, or a macOS factory to create macOS-style buttons and checkboxes. This ensures that all created objects are compatible with each other and makes it easier to switch between product families without changing the client code.
